## Featured project / 重点项目

### CrossChat

An English-first bilingual concept demo exploring a lightweight conversation flow across familiar messaging apps. The public release includes a static interactive frontend and redacted test screenshots; no live-service connection is included.

一个以英文为主、中英双语呈现的通讯概念演示，探索跨应用的轻量对话流程。公开版本包含静态交互前端与脱敏测试截图，不连接实时服务。

[View the live demo / 查看在线演示](https://qwermhao.github.io/crosschat-demo/) · [Explore the repository / 查看代码仓库](https://github.com/Qwermhao/crosschat-demo)
